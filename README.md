# AI-driven-Cyber-Security-Framework

This project presents an AI-driven framework for enhancing cybersecurity practices in
critical infrastructure organizations. The approach involves developing a phased risk
mitigation methodology consisting of a cyber risk classification model that incorporate SHAP graphs for model 
explainability, and fine-tuning the Llama 3.1 LLM 
using the Unsloth library to generate tailored cybersecurity policy recommendations based on the predicted risks. The fine-tuned LLM is run locally via GPT4All which provides an accessible platform for interactions with the model. The
implemented model achieves high accuracy in cyber risk prediction using the XGBoost algorithm
and the LLM's ability to generate context-specific recommendations demonstrate the potential of AI in enhancing cyber risk assessment.
